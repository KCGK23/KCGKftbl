# My Football Profile

This is a simple static website built with HTML and CSS.

## How to publish on GitHub Pages

1. Create a GitHub repository for this project.
2. In this folder, add the remote URL and push the branch:
   ```bash
git remote add origin https://github.com/<your-username>/<repo-name>.git
git branch -M main
git push -u origin main
```
3. In GitHub, go to the repository `Settings` > `Pages`.
4. Set the source branch to `main` and folder to `/root`.
5. Save and wait a few minutes for the site to appear.

Your published site will usually be available at:

`https://<your-username>.github.io/<repo-name>/`

## Notes

- `index.html` is the homepage.
- `styles.css.css` contains the styling.
- Image files are included in the project folder.
